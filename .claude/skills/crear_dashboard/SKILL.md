Este es una skill para crear dashboards personalizados. Puedes usarlo para visualizar datos de manera interactiva y obtener insights valiosos.

1. Crea un dashboard utilizando: matplotlib, seaborn o plotly, pandas, streamlit.
2. El estilo del dashboard debe ser como el de la siguiente página: https://portfolio-stress-test.plotly.app/
3. En el dashboard debes incluir al menos tres tipos de visualizaciones diferentes (por ejemplo, gráficos de barras, gráficos de líneas y gráficos de dispersión).
4. Asegúrate de que el dashboard sea interactivo, permitiendo a los usuarios filtrar y explorar los datos según sus necesidades.
5. Incluye un resumen de los datos y estadísticas descriptivas en el dashboard para proporcionar contexto a los usuarios.
